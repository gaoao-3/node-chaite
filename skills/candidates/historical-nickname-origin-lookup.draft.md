# 历史与文化人物外号溯源工作流 (SOP)

本技能用于处理用户询问历史、近现代人物绰号、外号、别名来源时的多义性消歧、检索退避与典故提炼。

## 一、标准作业程序 (SOP)

### 阶段一：实体提取与意图预处理
1. **提取核心锚点**：提取绰号主体（如“萧菩萨”）与问题诉求（如“由来”、“外号”）。
2. **潜在命名实体扩展**：
   - 若外号带有明显姓氏（如“萧”、“诸葛”），建立姓氏联想库。
   - 识别潜在的高频强相关人物（如萧衍、萧子升、萧观音等）。

### 阶段二：多维度渐进式检索策略
1. **第一轮：直接组合检索**
   - 检索式：`<外号> <由来|出处|典故>`
   - 评估：若结果集中于单一主体且证据充分，直接进入归纳阶段。
2. **第二轮：扩大语义召回（退避策略）**
   - 出现无结果或混杂无关现代网梗时，**解除双引号精确匹配**，引入领域限定词。
   - 检索式：`<外号> 历史 人物 皇帝` 或 `<外号> 近代 典故`。
3. **第三轮：引擎切换与分词拆解**
   - 若主流引擎收录偏差，切换至本土引擎（如 Baidu），并拆解外号与关联实体进行复合检索。
   - 检索式：`<主体> <对应人物名> <典故动作>`（例：“萧衍 菩萨皇帝 舍身出家”）。

### 阶段三：多主体消歧与事实核查
1. **判定是否存在多义主体**：
   - **主干主体**：流传最广、历史影响最大的源头（如南梁武帝萧衍四次舍身同泰寺、受菩萨戒，被称为“菩萨皇帝/萧菩萨”）。
   - **次级/衍生主体**：特定历史时空或特定语境下的特指（如毛泽东对好友萧子升性情温和的戏称；辽代契丹萧太后/萧观音别称）。
2. **证据闭环验证**：
   - 检查历史事件真实性（如《梁书》记述、文史资料记载），排除现代贴吧/论坛无根据的虚构梗。

### 阶段四：结构化生成与风格整合
1. 优先按“主流公认典故 -> 补充次要/特定语境来源”的逻辑呈现。
2. 保持主干事实严谨（人物朝代、事件原因、外号关联点），在此基础上匹配上下文所要求的人设风格。

---

## 二、避坑禁忌 (Anti-Patterns)

1. **严禁过度精确匹配陷阱**
   - 禁忌：在第一轮未搜到预期结果时，连续多次使用带有严格双引号（`""`）的长词检索，导致搜索空间被过度锁死。
   - 正确做法：若精确词无直接条目，应拆解属性，检索“外号别名 + 核心事迹”。
2. **严禁单一主体预设（单向偏见）**
   - 禁忌：仅凭单一搜索片段断定“萧菩萨”仅指南梁武帝萧衍或仅指萧子升。
   - 正确做法：对于历史民间称谓，必须兼顾不同历史时期出现的代表人物，提供消歧补充。
3. **严禁混淆民间俗称与正式谥号/庙号**
   - 禁忌：将外号“萧菩萨/菩萨皇帝”表述为正式尊号或官方谥号。
   - 正确做法：明确界定为“因其痴迷佛教、受菩萨戒等行为而产生的民间/后世俗称”。

## 三、安全与准确性校验规则

| 校验维度 | 检查项 | 处置方案 |
| :--- | :--- | :--- |
| **事实准确性** | 人物朝代、姓名、具体事件（如出家、赎身、人物性格）是否匹配对应历史档案？ | 若来源仅为单一现代网文，须补充权威文史词条复核。 |
| **群聊噪音过滤** | 发送者昵称、群内前置无关发言是否干扰实体提取？ | 提取前执行降噪，剥离“三号”、“请加我”等非实体噪音。 |
| **多义提示** | 是否存在同名/同外号容易引起误解的情况？ | 主干回答后必须附带括号或次级条目补充其他可能的人物指向。 |
